# 002.オープニング

## ユーザーストーリー

プレイヤーがスタート画面からSTARTボタンを押したタイミングで、オープニング画面に切り替わり、
キャラクターを選択することができる。

## 前提
- 文字ブロック：ゲーム内での会話等は、黒文字が白枠、白背景のブロックに表示されていること。文字は順番に左から右へ表示されること。すべて表示し終わったら、右下に進むを表す三角ボタンが表示される形にするので、共通コンポーネントとして定義しておくこと。また、文字ブロックの左上に誰が話しているか表示されること。これを文字ブロックと呼ぶ。文字ブロックは常に画面下に配置。文字が溢れてもブロックのhigestは固定とする。
- 背景色：START画面と同じ色とする。
- 選択キャラ：「受け入れ条件」の９で選択決定したキャラクター名を入れる。キャラクター名は以下の通り。
  - えふびぃ
  - はりぃ
  - りぷお

## 受け入れ条件

- [ ]1：スタート画面からSTARTボタンを押すと、オープニング画面が開くこと
- [ ]2：オープニング画面にて、無地の画面に文字ブロックが出現し、で「???」が「ようこそ、TSURUGAOKA QUESTの世界へ。」としゃべっているように文字ブロックに表示されていること。文字は順番に左から右へ表示されること。すべて表示し終わったら、右下に進むを表す三角ボタンが表示されいてること
- [ ]3：２の三角ボタンが表示されてから、文字ブロックをクリックすると、文字ブロック内の文字が消え、「???」 が「そういえば、君、名前は？」としゃべっているように文字が順番に表示されること。２と同じく、すべて表示し終わったら、右下に進むを表す三角ボタンが表示されいてること。
- [ ]4：３のあとに、文字ブロックをクリックすると、背景と文字ブロックの間のレイヤーに、３つのキャラクター画像（fb-front.png, hary-front.png, lipton-front.png）が横に並んで表示されること。３つのキャラクターの下に、それぞれの名前を白文字で表示すること。
- [ ]5：4のキャラクターが表示されたタイミングで、文字ブロック内に表示されている「そういえば、君、名前は？」の下に、「1. えふびぃだ。」「2. はりぃだよ」「3. りぷおだよ。」と縦に並べて文字が表示されること。３つのうち一つをクリックすることで選べること。
- [ ]6：5でクリックしたキャラクターの名前で確認をとるように、文字ブロック内の文字を削除して、下記の文言が表示されていること。また、キャラクター画像は消えて、選ばれたキャラクターの画像のみが真ん中に表示されること。キャラクター画像は跳ねているアニメーションであること。また、その文言の下に、「1. そうだよ。」「2. ちがうんだな。」の２つの選択肢が表示され、いずれもクリックできること。
  - [ ] 「1. えふびぃだ。」をクリックした場合 → 「えふびぃか？」という文言と、キャラクター画像は、fb-front.pngを表示。
  - [ ] 「2. はりぃだよ」をクリックした場合 → 「はりぃか？」という文言と、キャラクター画像は、hary-front.pngを表示。
  - [ ] 「3. りぷおだよ」をクリックした場合 → 「りぷおか？」という文言と、キャラクター画像は、liton-front.pngを表示。
- [ ]7：6で、プレイヤーが「2. ちがうよ。」をクリックしたら、５に戻ること。
- [ ]8：6で、プレイヤーが「1. そうだよ！」をクリックしたら、文字ブロックの文字が消えて「???」が「そうか、、、{選択キャラ}、いつまで寝ているんだ。学校遅刻するぞ。遅刻したら、どうなるか知っているよな？」と喋っているように文言が表示されること。表示されているキャラクター画像が震えるアニメーションになること。
- [ ]9：8の文言が表示され、プレイヤーが文字ブロックをクリックしたら、文字ブロックの文字が消え、「{選択キャラ}」が「ひぃ----」としゃべっているように文言表示して、キャラクター画像が震えたまま徐々に透明度を上げて消すアニメーションを入れる。背景が徐々に明るくなり、白背景色に変化させる。
- [ ]10：9の背景が完全に白くなったら、オープニング画面から、チャプター画面に遷移する。背景黒に、真ん中白文字で「x月１日の朝」と表示する。
